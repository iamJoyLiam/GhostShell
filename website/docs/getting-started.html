5 分钟跑起第一个会话

从安装到连上服务器：5 步，每步约 1 分钟。跟着做就行。

第 1 步

安装

  1. 1

    按芯片下载 DMG

    Apple Silicon 选 arm64 版，Intel Mac 选 x86_64 版。

  2. 2

    拖进 Applications

    打开 DMG，把 Bonk 拖进 Applications 文件夹。

  3. 3

    过 Gatekeeper

    右键应用 → 打开，或去 系统设置 → 隐私与安全性 里允许。

第 2 步

添加第一台主机

  1. 1

    点 ＋ 快速连接

    点工具栏 ＋，填主机地址、端口和用户名。

  2. 2

    密码或私钥都行

    凭据存进 macOS Keychain，下次自动填充。

  3. 3

    核对一次主机指纹

    第一次连确认主机指纹，之后点主机即连。

  4. 4

    有现成配置？一键导入

    自动识别 SSH config、Tabby、iTerm2、CSV，主机列表直接生成。

第 3 步

日常操作

deploy@prod ~ $ uptime 09:42:01 up 12 days, 3:17, load average: 0.08, 0.03, 0.01
  • 胶囊标签页一台主机一个胶囊 Tab，圆点即连接状态。
  • 分屏 + 广播窗口内水平/垂直切多格；广播输入把同一条命令发给所有格子。
  • Quake 下拉终端任何应用里按 ⌘` 呼出，用完收起。
  • 行内补全 + Agent灰字跟随按 Tab 接受；复杂任务交给 Agent 模式分步执行。
  • 工作区把整套窗口存成工作区，明天一键回到昨天现场。
  • 会话录制重要操作点录制存档，列表里回放、删除。
第 4 步

传文件、打隧道

  • SFTP工具栏文件夹图标开可视化文件浏览器，拖拽上传下载；也支持 Zmodem。
  • 端口转发本地 / 远程 / SOCKS5 三种隧道，看内网后台、连远端库都走它。
  • 跳板机多级跳板在连接设置里配好，内网机器一次直达。
  • 串口调交换机、开发板直接连串口，参数在连接里配。
第 5 步

自愈与排错

  • 约 1 秒建连VNext 混合引擎：原生优先、OpenSSH 兜底。
  • 睡眠断网自动自愈合盖、切网、抖动后自动重连，不用手动重拨。
  • 报错说人话认证失败自动重试，并告诉你是密码错、密钥不对还是指纹变了。
FAQ

常见问题

  • 要注册账号吗？不要。下载、加主机、连接，离线照样用。
  • 我的命令会上云吗？不会。凭据只在 Keychain，历史只在本地。
  • Bonk 有 AI 吗？有：Agent 模式分步执行任务，行内补全边输边猜，支持 Copilot / Claude / OpenAI / Gemini / Ollama 或自定义提供商。
  • 能当本地终端用吗？能，是完整终端模拟器，但主场是远程服务器。
